Regla de Integridad Contable (SPC-006)

Moneda fija: una vez que una cuenta tiene movimientos registrados, su moneda no puede ser modificada para preservar la trazabilidad contable y el cierre de balances. Los ajustes por diferencias de cambio o efectivo físico deben realizarse exclusivamente mediante transacciones de arqueo o ajuste de capital.
